## Proyectos

1. **Proyecto final - Comparativa de emisiones de CO₂**
   - Objetivo: predecir las emisiones de CO₂ de distintos tipos de vehículos y comparar si los vehículos híbridos contaminan más o menos que los de combustión.
   - Tecnologías: Python (Pandas, Numpy, Matplotlib, Seaborn), scikit-kearn
   - Fases: limpieza de datos, análisis exploratorio, PCA mixto, clustering, regresión lineal y random forest.
   - Conclusiones: identificación de patrones según marca, potencia y tipo de combustible.
   - [Ver proyecto](./Proyecto%20final)

2. **Análisis de ventas - Cafetería**
   - Objetivo: Detectar patrones de consumo y evaluar la rentabilidad de productos.
   - Tecnologías: Python (Pandas, NumPy, Seaborn), Power BI.
   - Fases: Limpieza de datos, análisis exploratorio, creación de dashboard en Power BI.
   - Conclusiones: Productos más vendidos, comportamiento por meses y días de la semana, mantenimiento de un catálogo variado.
   - [Ver proyecto](./Proyecto%20cafetería)
